# The Junk Drawer

Little static tools, served with GitHub Pages. Each tool lives in its own folder with an `index.html`; add a link to it on the root `index.html`.

| Tool | What it does |
| --- | --- |
| [piroshki](piroshki/) | NaNoWriMo word tracker for two stories, each with its own goal. Log words per story per day and watch a tray of 12 piroshki bake as both goals fill. Data stays in a cookie in the browser. |
