# The Junk Drawer

Little static tools, served with GitHub Pages. Each tool lives in its own folder with an `index.html`; add a link to it on the root `index.html`.

| Tool | What it does |
| --- | --- |
| [piroshki](piroshki/) | NaNoWriMo word tracker for up to five stories, each with its own goal. Log words per story per day; a tray of 12 piroshki bakes toward all the goals added together. Data stays in a compact cookie in the browser. |
| [recipes](recipes/) | Family recipe box. Each family is a JSON file in `recipes/data/`, listed in `families.json`. Search, filter by family, scale servings, switch between as-written / US / metric (cups to grams by ingredient weight, oven temps, pan sizes), tick off ingredients and steps, keep the screen on, YouTube videos (`"video": "<link>"`), tap-to-start timers from times in the steps, and a grocery list that adds up ingredients across picked recipes. |
