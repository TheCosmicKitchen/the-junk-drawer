# The Junk Drawer

Little static tools, served with GitHub Pages. Each tool lives in its own folder with an `index.html`; add a link to it on the root `index.html`.

| Tool | What it does |
| --- | --- |
| [piroshki](piroshki/) | NaNoWriMo word tracker: log words per day, watch a tray of 12 piroshki bake on the way to 50,000. Data stays in a cookie in the browser. |
